# Changelog

## 0.5.1 — 2026-10-30 · иконка приложения обновляется сама
- Причина старого логотипа на телефонах: service worker «Цитадели» отдавал `/icons/*` «сначала из кеша», а адреса иконок не менялись — при обновлении и переустановке PWA телефон мог получить прежнюю картинку.
- Новые адреса иконок `/icons/smmkadr-*.png` (manifest, favicon, уведомления, экраны входа и PIN; прежние `icon-*.png` тоже перезаписаны). Смена адреса в manifest заставляет Android обновить значок установленного приложения.
- Service worker `smmkadr-v4`: иконки и manifest больше не кешируются, установка не срывается из-за одного файла, старые кеши удаляются.
- Автообновление: проверка новой версии при запуске, при возврате в приложение и раз в 30 минут, затем автоматическая перезагрузка.
- Кнопка «Обновить приложение» (Настройки → Установка и о приложении, «О приложении») — очищает кеш устройства без выхода из аккаунта.

## 0.5.0 — 2026-10-30 · SMM KADR: ребрендинг, мастер проекта, база клиентов, сайт по презентации
- **Бренд SMM KADR.** «Цитадель» убрана из интерфейса, PWA, заголовков, входа, уведомлений, офлайн-страницы, инструкций и выгрузок (служебные ключи `citadel.*`, таблицы и маршруты не переименовывались). Логотип — вектор по оригинальному знаку (геометрия снята с маски исходного файла из PDF), надпись — контуры Montserrat ExtraBold, без подписи TARGET | CONTENT | VIDEO. Ассеты: `assets/brand/*.svg` → `npm run icons` (иконки 32–512, maskable, favicon, apple-touch-icon, PNG-логотипы, OG). Фирменный синий `#1845D2` вместо красного; заголовки — Montserrat. Service worker `smmkadr-v3` сбрасывает старый кеш.
- **Мастер «Добавить проект»** (`/app/projects/new`, первый пункт «+»): 3 шага «Клиент → Проект и тариф → Команда и оплата». Новый клиент или «Уже в базе» с поиском по телефону/ФИО/компании; подсказка о дубле при вводе. Тариф подставляет тип, цену, состав и метод сторис; договор хранит снимок версии тарифа. Заявленная оплата создаётся как платёж «на подтверждении», остаток — от подтверждённой суммы; запуск — по прежним правилам допуска. Всё одной транзакцией `project_wizard_create` с ключом идемпотентности; без администратора — задача-напоминание автору. Черновик мастера — на устройстве по кнопке.
- **База клиентов** (`/app/clients`): автоматически пополняется мастером; поиск по ФИО/телефону/компании/нише, фильтры по нише и проектам, карточки на телефоне (звонок, WhatsApp), таблица на ноутбуке; карточка клиента — контакты, ответственный, все проекты со статусами и датами, заявки, последнее взаимодействие. Ручное добавление — в свёрнутом блоке, дубли по телефону запрещены. Пункт «Добавить клиента» убран из «+».
- **Публичный сайт** по коммерческому предложению 2026: 15 секций (первый экран, команда, 7 тарифов, договор и гарантия, оборудование, отчёт, реальные профили, партнёры, контакты) с текстами, ценами и сносками презентации и её оригинальными изображениями (WebP); синий градиент, тёмно-синие карточки, бирюзовые акценты; адаптив 320–1440 px без переносов внутри слов. Кнопки тарифов подставляют тариф в форму заявки.
- **CMS** (`/app/cms`): список секций (порядок, видимость), редактор секции (все тексты, цена/тариф, цифры, списки, команда, карточка, сноска, изображения с загрузкой в хранилище, кнопки), предпросмотр черновика, публикация с версиями, «вернуть текст презентации». Предупреждение, если цена на сайте расходится со справочником тарифов. Журнал изменений блоков и настроек.
- **Заявки с сайта**: тариф сохраняется в лиде (`tariff_id`), уведомление «Новая заявка с сайта» содержит имя, компанию/нишу, тариф и телефон и ведёт в карточку заявки.
- Миграции 0018 (телефоны, поиск клиента, мастер, `lead_convert` по ключу телефона, `submit_lead` с тарифом) и 0019 (блоки `slide`, аудит CMS, контент презентации; прежние блоки скрыты, не удалены). Тесты: `project-wizard.test.ts` (+14, всего 103), SQL `supabase/tests/smm_kadr_wizard.sql` (38 проверок).

## 0.4.0 — 2026-10-29 · финальное ТЗ: сотрудники, таргет, финансы, инструкции
- **P0: 404 при открытии сотрудника.** Причина воспроизведена: у `profiles` и `departments` две связи (`profiles_department_id_fkey` и `departments_head_fk`), PostgREST отвечал `PGRST201`, а страница превращала ошибку в `notFound()`; список «Сотрудники» по той же причине был пустым. Внешний ключ указан явно, ошибки показываются как «Ошибка загрузки» / «Недостаточно прав», 404 — только для несуществующей записи.
- Утверждение/блокировка — RPC `employee_set_status` (0013): право `employees.manage`, ровно одна строка, идемпотентно, уведомление «Ваш доступ открыт», при блокировке — сброс PIN-устройств, сеансов и одна задача на отзыв внешних доступов. Экран «Ожидание утверждения» сам перепроверяет статус.
- **Рабочее место таргетолога** (0014): «Мои проекты» (клиент, ниша, контакт, план в день, факт USD/KGS раздельно, дни работы, активные видео, проверка), карточка кампании с разделами Обзор / Видео / Расходы / Клиент / Доступы / История, рабочий стол проекта, мастер новой кампании. Креативы с личным дневным бюджетом и ручными статусами, история статусов и бюджетов с датой действия, журнал расходов без перезаписи (идемпотентный ключ, распределение общего расхода по видео без удвоения, исправления с причиной). Доступ — только к назначенным проектам; таргетолог автоматически становится участником проекта своей кампании. Напоминание о плановой проверке (cron 10:00 Бишкек). Интеграций с рекламными API нет.
- **Арифметика финансов** (0015–0016): валюты не складываются нигде (сводки, главная, отчёты, зарплаты, «Мои выплаты»); движение по кассе только в валюте кассы; платёж — в валюте счёта; выплата зарплаты — в валюте начисления; долг по зарплате без черновиков; план-факт: просрочка исполнителя отдельно от просрочки проверки, сторис — согласованные «готово/осталось».
- Мобильные бухгалтерия, зарплаты и отчёты: карточки по валютам, разделы-строки, быстрый выбор месяца, таблицы-карточки с подписями, отчёты «Проекты / Сотрудники / Финансы» с фильтрами. Десктопные таблицы и CSV сохранены.
- **Инструкции** `/app/help`: 13 тем с поиском, словарь статусов, ссылки только в разрешённые разделы; «О приложении и авторе» с текстом владельца.
- 4-я вкладка «Реклама» для таргетолога, действие «Записать расход рекламы» в «+», главная бухгалтера и таргетолога.
- Тесты: `ads-math.test.ts`, `money-math.test.ts`, расширен `nav.test.ts` (89 тестов), SQL `supabase/tests/ads_finance.sql`. Замечания Supabase Advisors к новым функциям закрыты (0017).

- Обезличенные замеры скорости (п. 9.1 ТЗ): Web Vitals и время перехода «тап → каркас» и «тап → данные», таблица `web_vitals` (миграция 0012, хранение 30 дней), экран «Отчёты → Скорость приложения» (p75). С localhost не отправляются. Тест `vitals.test.ts`.
