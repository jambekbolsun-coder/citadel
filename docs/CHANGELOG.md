# Changelog

## 0.1.0 — 2026-10-29
Первая версия «Цитадели» (этапы 1–5 ТЗ):
- Схема Supabase (8 миграций): ~60 таблиц, RLS на всех, 50+ RPC бизнес-правил, представления план-факт/сверки/зарплат, pg_cron-напоминания, Storage-бакеты с политиками, Realtime.
- Публичный сайт из CMS, лид-форма с антиспамом и мгновенными уведомлениями.
- Авторизация: первый владелец, QR-приглашения, утверждение, PIN, восстановление пароля, выход на всех устройствах.
- Продажи: CRM-воронка с историей, клиенты, тарифы с версиями.
- Производство: мастер проекта, платёжный гейт, периоды, план, контент со state machine, размещения, сторис, задачи, съёмки, реклама, доступы в Vault, ежедневные проверки.
- Календарь год/месяц/неделя/день, загрузка команды.
- Финансы: счета, поступления с независимым подтверждением, дебиторка, расходы и имущество, кассы и сверка, CSV.
- Зарплаты: условия с историей, начисления, утверждение, авансы, долг, «Мои выплаты».
- Отчёты, отчёт клиенту и черновик акта, журнал аудита, матрица прав.
- PWA: manifest, иконки (в т.ч. maskable) из логотипа, service worker с безопасной стратегией, установка Android/iOS.
