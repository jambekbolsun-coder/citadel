# Илбирс, приветствие и соревнования — согласованный план (03.11.2026)

## Решения владельца
| Вопрос | Решение |
|---|---|
| Персонаж | 3D-илбирс в синем худи SMM KADR, 8 эмоций (`assets/mascot/`) — утверждён |
| Тон | смешно-обиженный, без настоящей злости |
| Заставка | раз в день при первом открытии |
| Соревнование | формат выбирает владелец при создании сезона: все / по отделам / по ролям; баллы в % от плана |
| Активность в приложении | учитывать: только «был ли сотрудник в приложении в этот день», сотрудники видят, что это считается |
| Премия | суммы за 1–2–3 места → кнопка «Начислить премии» создаёт черновики в «Зарплатах» |
| Во время сезона | сотрудник видит только свои баллы и разбивку; чужие — после «Показать результаты» |
| Обращение «молодец/умница» | поле в профиле «он / она / не указывать»; по умолчанию — нейтральные фразы. Пол по имени не угадываем |

## Эмоции илбирса → когда показываются
| Файл | Эмоция | Правило (по данным текущего сотрудника) |
|---|---|---|
| 05-angry | «злой» | 3+ просроченных задач/материалов или просрочка > 2 дней |
| 04-strict | строгий | 1–2 просрочки |
| 08-remind | напоминает | сегодня срок сдачи, ещё не сдано |
| 02-happy | радостный | на сегодня всё сдано / только что закрыта работа |
| 03-proud | гордый | серия ≥ 5 рабочих дней без просрочек или призовое место |
| 06-calm | спокойный | задач нет |
| 07-celebrate | празднует | церемония итогов, день рождения |
| 01-kind | добрый | всё остальное, приветствие |
Приоритет сверху вниз. Фразы — набор вариантов на каждую эмоцию, владелец может менять.

## Этап 1. Илбирс и приветствие
- Ассеты: убрать белый фон, WebP/AVIF 30–60 КБ, 2 размера (заставка ~480 px, иконка ~160 px), `public/mascot/`.
- Заставка на весь экран: «Доброе утро / Добрый день / Добрый вечер / Доброй ночи, {имя}!» (время Бишкека: 5–11 / 11–17 / 17–23 / 23–5), илбирс по правилу эмоций, одна фраза о делах + кнопка (например «Открыть просрочки»). Раз в день (на устройстве), 2–3 с, тап закрывает, `prefers-reduced-motion` — без анимации, после PIN-экрана.
- Главная: маленький илбирс с подсказкой дня; пустые экраны — спокойный илбирс; после «Сдать работу» — короткая радость.
- Профиль: «Как к вам обращаться» (он/она/не указывать), дата рождения (необязательно).
- Настройки владельца: тексты фраз по эмоциям.

## Этап 2. Соревнования
- **Сезон** (владелец, право `employees.manage` или новое `contests.manage`): название, даты, участники (все / отделы / роли), формат рейтинга (общий / внутри отдела / внутри роли), показатели и веса, призы 1–2–3 (сумма KGS и/или текст).
- **Показатели** (из реальных данных, только после утверждения/закрытия):
  задачи вовремя; утверждённые материалы; дисциплина (−за просрочки); качество (меньше правок); сторис по плану; дни активности в приложении; «Спасибо» от коллег (по желанию, ≤ 3 в неделю).
  Задачи, созданные себе самому, не считаются. Баллы — в % от плана, чтобы разные должности были сравнимы.
- **Активность**: таблица «сотрудник × день» (одна отметка в день при открытии приложения), без деталей действий.
- **Во время сезона**: «Мои результаты» — свои баллы, разбивка, дни до конца.
- **Итоги**: после даты окончания владелец нажимает «Показать результаты» → баллы фиксируются (снимок), всем уведомление и церемония: пьедестал 1–2–3, празднующий илбирс, конфетти. Архив «Зал славы».
- **Премии**: «Начислить премии» → черновик премии победителям за месяц сезона: если начисление месяца в черновике — `bonus_minor`, если уже утверждено — корректировка с причиной «Премия: {сезон}, {место} место». Деньги сами не выплачиваются, обычное утверждение. Повторное нажатие не задваивает.

## Этап 3. Дополнительно
Значки достижений, серия без просрочек 🔥, личные итоги месяца 1-го числа, поздравление с днём рождения.

## Принципы
Права — в БД (RLS + RPC). Деньги — в тыйынах. Ничего не ломать: только новые таблицы/поля/функции. Тесты: правила эмоций, приветствие по времени, расчёт баллов и мест (ничьи), идемпотентность премий.
