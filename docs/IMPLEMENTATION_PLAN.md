## Не входит в первую версию (по ТЗ — отдельные расширения)
- Автоимпорт рекламной статистики Meta/Google, автопостинг, Telegram, банковская сверка, ЭЦП.
- Кыргызская локализация (структура строк готова к выносу).

## Версия 0.2 (дополнения)
- ✅ Web Push при закрытом приложении: Настройки → Уведомления → «Включить уведомления» (на каждом устройстве; iPhone — только установленное приложение, iOS 16.4+).
- ✅ Повторяющиеся серии задач и съёмок: каждые N дней/недель (по выбранным дням), по месяцам — то же число, N-й или последний день недели; до даты или N раз (максимум 60). Остановка «этого и следующих» с причиной.
- ✅ Перетаскивание в календаре (месяц/неделя, компьютер): задачи, съёмки, сроки подготовки и публикации материалов. Время суток сохраняется, причина и история обязательны, участники съёмки подтверждают заново. На телефоне — перенос через карточку.

## Версия 0.3 (мобильный редизайн)
- Оболочка, «+», настройки, поиск, ролевая главная, мобильный календарь, производительность — см. CHANGELOG 0.3.0.

## Следующие шаги
1. Владелец проходит `/setup`, приглашает сотрудников.
2. В Supabase → Authentication → URL Configuration указать Site URL = адрес Vercel и добавить `https://<домен>/auth/callback` в Redirect URLs.
3. Подключить собственный SMTP (лимит встроенной почты Supabase — несколько писем в час).
4. Задать нормативы производства (Настройки → Компания и нормативы).
