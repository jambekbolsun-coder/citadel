# План тестирования

## Автоматические
- `npm test` — Vitest: деньги без float (15 000/60 000 → 45 000; 50 000 − 15 000 → 35 000), часовой пояс, склонения, нагрузка 10×8=80 → 2,67/3,64.
- `npm run typecheck`, `npm run lint`, `npm run build` — в CI (`.github/workflows/ci.yml`).
- `supabase/tests/push_series.sql` — серии (одно уведомление на серию, остановка «этот и следующие», исполнитель не может остановить серию), перенос контента (права, история, уведомление), очередь push (только https, claim, удаление мёртвой подписки).
- `supabase/tests/business_rules.sql` — интеграционный тест в БД (выполнить в SQL Editor; результат — ошибка с текстом `TEST OK: {...}`, все изменения откатываются).

## Ручные сценарии приёмки (п. 27 ТЗ)
1. `/setup` → регистрация владельца → подтверждение email → «Стать владельцем».
2. Сотрудники → Добавить → QR → открыть ссылку на телефоне → регистрация тем же email → профиль → владелец утверждает. Повторное открытие ссылки — «уже использовано»; отозванная — «отозвано».
3. Настройки → Безопасность → установить PIN; закрыть вкладку, открыть /app — экран PIN; 5 неверных — выход и вход паролем.
4. Отправить заявку на сайте → у владельца без перезагрузки появляется тост и счётчик; повтор формы не создаёт дубль.
5. Лид → взять → стадии → клиент → проект (мастер) → поступление (менеджер) → подтверждение (бухгалтер) → чек-лист → допуск → план → утверждение.
6. Материал: назначить → в работе → на проверку (ссылка) → правки (причина) → сделано → размещение ×2 → выложено → проверено.
7. Съёмка: назначить двоих на пересекающееся время — предупреждение о конфликте; перенос — участники подтверждают заново.
8. Расход «Камера» с «учесть как имущество» → подтвердить → карточка имущества, одно списание в движениях; сторно — компенсирующая запись.
9. PWA: Android Chrome — «Скачать приложение» вызывает системную установку; iPhone Safari — инструкция «Поделиться → На экран Домой».
10. Без сети — офлайн-страница, никакого ложного «сохранено».
11. Push: Настройки → Уведомления → «Включить» → «Отправить тестовое» → закрыть приложение → уведомление приходит, клик открывает Цитадель.
12. Серия: задача «каждую неделю пн, чт, 8 раз» → 8 задач, одно уведомление исполнителю; на 3-м повторе «Отменить этот и следующие» → первые 2 остаются.
13. Календарь (компьютер): перетащить задачу на другой день → запрос причины → срок перенесён, время то же, в истории задачи — перенос.
