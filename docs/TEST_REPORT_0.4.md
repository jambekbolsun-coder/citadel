## 404 при одобрении сотрудника — воспроизведено и исправлено
- Причина: `profiles.select("*, departments(name)")` → PostgREST `PGRST201` (две связи profiles↔departments). Ошибка игнорировалась → `notFound()`. Список сотрудников по той же причине был пустым.
- После исправления (localhost, вход владельца): список «Ждёт утверждения» показывает реального ожидающего сотрудника, карточка открывается, видны кнопка «Утвердить и открыть доступ», роли, права и условия зарплаты из приглашения (одна запись, без дублей).
- Уведомление `employee.joined` в БД ссылается на `profiles.id` (проверено запросом).
- Кнопку утверждения реального сотрудника не нажимали — это решение владельца. Логику утверждения проверил SQL-тест: одна строка, повтор ничего не меняет, одно уведомление, без права — отказ, несуществующий ID — ошибка, свой статус — отказ, блокировка сбрасывает PIN-устройства и создаёт одну задачу.
